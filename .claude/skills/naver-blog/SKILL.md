# 네이버 블로그 후기 자동 파이프라인

1. 프로젝트 폴더의 `README.md`와 `CLAUDE.md`를 읽는다.
2. `CLAUDE.md`의 **파이프라인** 1~6단계를 순서대로, 중간에 묻지 않고 실행한다.
   - 사진 파일이 없을 때만 사진 폴더 경로를 한 번 묻는다.
3. **절대 규칙**을 지킨다.
   - 최종 발행 금지, 비밀번호 다루지 않기, 로그인 화면에서 멈추기
   - Aside 작업은 단계마다 한 번만 실행한다. 실패해도 자동으로 다시 하지 않는다.
4. 끝나면 한국어로, 쉬운 말로 결과와 사용자가 직접 할 일을 알린다.

인자: $ARGUMENTS (사용자가 같이 보낸 기초 내용. 비어 있으면 대화에서 찾는다)
