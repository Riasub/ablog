## 1. 전체 흐름

```
[1] 사용자 사진·메모 → [2] claude.ai 아티팩트 페이지로 초안 작성
→ [3] 사용자 피드백 반영 (아티팩트 같은 URL에 재게시)
→ [4] Aside CLI로 네이버 블로그 글쓰기 화면에 붙여넣기 → 임시저장
→ [5] 사용자가 직접 확인 후 발행
```

- 발행은 **항상 사용자가 직접** 합니다. 에이전트는 임시저장까지만 합니다.
- **자동 실행:** 사용자가 기초 내용을 보내거나 `/naver-blog`를 입력하면 [1]~[4]가 자동으로 돌아갑니다. 실행 순서는 `CLAUDE.md`에 있습니다.
- 태그를 넣기 위해 **발행 설정 창을 여는 것은 사용자가 허락했습니다**(2026-11-22). 창 안의 최종 발행 버튼은 누르지 않습니다.

### 폴더 구조

| 경로 | 용도 |
|---|---|
| `CLAUDE.md` | 자동 실행 조건과 파이프라인 순서 (에이전트가 자동으로 읽음) |
| `.claude/skills/naver-blog/SKILL.md` | `/naver-blog` 명령 |
| `templates/blog-page.html` | 초안 페이지 틀 (`{{TITLE}}` `{{TAGS}}` `{{ARTICLE}}` `{{CHECKS}}` `{{PAGE_TITLE}}`) |

| `posts/<YYYY-MM-DD>_<가게명>/` | 글마다 사진, `notes.md`(사용자 메모와 아티팩트 URL), `page.html` |

## 3. 환경 · Aside CLI 설정

- OS: Windows 10, PowerShell. 작업 폴더: `C:\Users\suebin\Desktop\claude_PJT`
- Aside CLI 버전: `1.26.1115.1556`
- Aside가 없으면 실행하지 말고, Aside 앱의 **개발자 설정에서 CLI를 설치**해 달라고 사용자에게 말한다.

### 이미 적용한 설정

```powershell
aside settings save-sessions enable   # CLI 작업이 Aside 앱 채팅 목록에 남게 함
```

> ⚠️ 값은 `true`가 아니라 **`enable` / `disable`** 입니다(`aside settings --help` 기준).
> 현재 설정 확인: `aside settings get`

### 자주 쓰는 명령 (모두 --help로 확인함)

| 목적 | 명령 |
|---|---|
| 브라우저 작업 실행 | `aside "작업 내용"` |
| 세션 목록 | `aside session list` |
| 세션 상태·마지막 답 | `aside session inspect <세션ID>` |
| 세션 이어서 하기 | `aside session resume <세션ID> "추가 지시"` |
| 세션 멈추기 | `aside session stop <세션ID>` |

### 실행 팁

- 작업이 10분 넘게 걸릴 수 있으니 **백그라운드로 실행**하고 끝나면 출력 파일 끝부분을 읽는다.
- 출력이 길어서 잘리면 저장된 출력 파일의 **마지막 부분**에 최종 보고가 있다.
- 사용자가 Aside 앱에서 같은 세션을 직접 이어서 돌릴 수도 있다. **다시 실행하기 전에 `aside session list` / `inspect`로 이미 진행 중이거나 끝났는지 먼저 확인**한다(중복 저장 방지).
- Aside 작업 기록과 캡처는 `C:\Users\suebin\.aside\u\0\sessions\<날짜>_<세션ID>\tmp\` 에 저장된다.

## 4. 글 작성 규칙

### 제목 형식 (필수)

```
[지역] 가게명 내돈내산 후기 : (짧은 한 줄 감상)
```
예: `[탕정] 타코의 밤 내돈내산 후기 : 알 큼직한 타코야끼에 늦은 밤 한잔`

### 본문 구성 순서 (네이버 블로그 후기 5개를 참고해 정함)

1. 인사 + 한 줄 소개("○○ 다녀온 내돈내산 후기예요!")
2. 방문 계기 / 가게의 좋은 점 한 줄
3. 주문한 메뉴 요약
4. `━━━` 구분선 안에 **가게 정보**: 주소, 영업시간(라스트오더·휴무 포함), 전화, 참고사항
5. **▶ 메뉴판**: 종류별로 이모지와 가격 정리 + "네이버 플레이스 기준이라 바뀔 수 있어요"
6. **▶ 메뉴별 후기**: `메뉴명 (가격)` 제목 → 사진 → 사진 설명 → 감상
7. 💡 꿀팁 한 줄
8. **▶ 총평** + `✔️ 이런 분께 추천` 목록
9. 맨 끝: `[📍 장소: 가게명]` 줄 (에디터의 '장소' 버튼으로 지도를 넣을 자리)

### 내용 원칙

- **방문일은 넣지 않는다.**
- 맛이나 경험은 **사용자가 말한 것만** 쓴다. 다른 사람 후기의 경험을 사용자 경험처럼 쓰지 않는다.
- 가게 정보(메뉴, 가격, 영업시간)는 네이버 플레이스에서 가져온다.
- 말투는 친근한 존댓말 + 이모지 조금(🐙 😊 🍺 💡 ✔️).
- 정보가 비거나 확실하지 않으면 지어내지 말고, 페이지 위쪽 **'발행 전에 확인하세요'** 상자에 적어 사용자에게 묻는다.
- 업체가 올린 메뉴판 사진이 없으면 메뉴판은 **글자로** 정리한다.
- 태그는 10~12개. 지역+업종(#탕정술집), 가게명, 메뉴명, 특징(#늦게까지하는술집), `#내돈내산`.

## 5. 아티팩트(초안 페이지) 구조

- 첫 글 페이지: https://claude.ai/artifact/TtjLYKEU7iCfL9BeL2Fhz9 (비공개. 사용자 계정으로 로그인해야 열림)
- 한 단짜리 페이지이고, 위에서부터 이렇게 되어 있다.
  1. `발행 전에 확인하세요` 상자 (`section.check`)
  2. `1. 제목 칸에` + **제목 복사** 버튼 (`#copy-title`)
  3. `2. 본문에` + **본문 전체 복사** 버튼 (`#copy-body`) + 본문 (`#article`)
  4. `3. 태그 칸에` + **태그 복사** 버튼 (`#copy-tags`)
- 제목과 태그는 화면 글자(`.value`, `.tags`)와 스크립트의 `const DATA = {title, tags}` **두 군데**에 있다. 고칠 때는 둘 다 바꾼다.
- 사진은 본문 안에 base64 `<img>`로 들어 있다(페이지 약 2MB). 고칠 때는 사진 데이터는 그대로 두고 글만 바꾼다.
- 고친 페이지는 **같은 URL에 다시 게시**한다(새 URL을 만들지 않는다).

## 6. 네이버 블로그 에디터 — 알게 된 점과 주의사항

| 상황 | 대처 |
|---|---|
| **태그 칸 위치** | 태그 칸은 오른쪽 위 '발행' 버튼을 눌러야 뜨는 **발행 설정 창 안에만** 있다. 이 창을 여는 것은 사용자 허락을 받고 한다. 창 안 아래쪽의 **최종 '발행' 버튼은 절대 누르지 않는다.** 태그를 넣은 뒤 창을 닫고 에디터의 '저장'(임시저장)을 누른다. |
| **"다른 기기에서 수정되었습니다. 덮어쓸까요?"** | 예전 버전이 열린 탭에서 저장할 때 뜬다. **확인을 누르면 새 글이 예전 내용으로 덮어써진다.** 반드시 취소하고 멈춘다. |
| **예전 글쓰기 탭** | Aside는 사용자가 연 탭을 닫지 못한다. 예전 탭이 열려 있으면 자동 저장으로 새 글이 덮어써질 수 있으니, 사용자에게 **'나가기'로 닫아 달라고** 알린다. 글을 고칠 때는 항상 **새 탭에서 글쓰기 화면을 열고 임시저장 목록에서 최신 글을 불러온다.** 불러온 뒤 제목이 최신인지 꼭 확인한다. |
| **사진 붙여넣기** | '본문 전체 복사'로는 사진이 안 붙을 때가 있다. 그럴 때 Aside는 사진을 파일로 저장한 뒤 에디터의 사진 버튼으로 같은 자리에 넣었다. 다 넣은 뒤 사진 수와 순서를 확인한다. |
| **장소 넣기** | `[📍 장소: …]` 줄을 지우고 '장소' 버튼으로 검색해 넣는다. 지역(예: 탕정면 매곡한들5길 6-4)이 맞는지 확인한다. 맞는 곳이 없으면 줄을 그대로 두고 알린다. |
| **빈 표 칸** | 장소 줄을 바꾸고 나면 지도 위에 빈 1x1 표 칸이 남을 수 있다. 지도까지 같이 지워질 수 있어서 Aside가 손대지 않았다. 사용자에게 직접 지워 달라고 알린다. |
| **'첫글' 태그** | 블로그에 원래 '첫글' 태그가 있었다. 태그를 새로 바꾸면서 지워졌다. |
| **저장 확인 방법** | "임시저장이 완료되었습니다" 알림, 그리고 임시저장 목록의 **저장 시간이 바뀌었는지** 확인한다. |
| **네이버 지도 약관 화면** | `map.naver.com/p/entry/place/…`를 열면 약관 동의 화면이 뜬다. 동의하지 않고 대신 `pcmap.place.naver.com`에서 가게 정보를 읽는다. |
| **claude.ai 로그인** | Aside 브라우저가 claude.ai에 로그인돼 있지 않으면 아티팩트를 열 수 없다. 사용자가 직접 로그인해야 한다. |

## 7. Aside 작업 지시문 템플릿

### A. 새 글 임시저장

```
한 번에 이 글 하나만 처리해 줘.
1) <아티팩트 URL> 를 연다.
2) 새 탭에서 네이버 블로그 글쓰기 화면을 연다.
3) 페이지의 '제목 복사'로 제목 칸에 붙여 넣는다.
4) '본문 전체 복사'로 본문에 붙여 넣는다. 사진이 빠졌으면 페이지의 사진을 하나씩 같은 자리에 넣는다.
5) 본문 맨 끝 '[📍 장소: <가게명>]' 줄을 지우고, 에디터의 '장소' 버튼으로 '<검색어>'를 검색해 <주소> 가게를 그 자리에 넣는다. 안 보이면 줄을 그대로 두고 알려 준다.
6) (사용자 허락이 있을 때) '발행' 버튼으로 발행 설정 창만 열어 태그 칸에 '태그 복사'의 태그를 넣고, 창을 닫는다. 창 안의 최종 '발행'은 절대 누르지 않는다.
7) '임시저장'을 누르고 저장됐는지 확인한 뒤 멈춘다. '발행'은 절대 누르지 않는다.
지켜 줄 것: 네이버나 claude.ai 로그인 화면이 나오면 아무것도 입력하지 말고 멈춰서 알려 줘. 실패해도 같은 동작을 여러 번 반복하지 마.
끝나면 알려 줘: 임시저장 성공 여부와 저장 시간, 최종 제목, 본문 사진 수, 태그 목록, 장소 첨부 여부, 막힌 단계.
```

### B. 이미 임시저장된 글 고치기

```
한 번에 이 글 하나만 처리해 줘.
1) 열려 있는 예전 글쓰기 탭은 저장하지 말고 그냥 둔다(덮어쓰기 창이 뜨면 취소).
2) 새 탭에서 글쓰기 화면을 열고, 임시저장 목록에서 '<현재 제목>' 글을 불러온다. 제목이 맞는지 확인하고, 아니면 저장하지 말고 멈춘다.
3) 제목, 본문, 사진, 장소, 태그를 A 템플릿처럼 새 내용으로 바꾼다.
4) 임시저장을 누른다. '다른 기기에서 수정되었습니다' 창이 뜨면 취소하고 멈춘다.
5) 임시저장 목록의 저장 시간이 바뀌었는지 확인하고 멈춘다.
(지켜 줄 것과 보고 항목은 A와 같다)
```

### C. 자료 조사 (읽기만)

```
읽기만 하는 작업이야. 아무 글도 쓰거나 저장하거나 누르지(좋아요, 댓글, 공감 등) 마.
로그인 화면이나 약관 동의 화면이 나오면 동의하지 말고 다른 길(pcmap.place.naver.com)로 읽어.
1) 네이버 플레이스 <place URL>의 메뉴·가격·영업시간을 적어 줘.
2) 업체가 직접 올린 메뉴판 사진이 있으면 1장만 <폴더>에 저장해 줘. 방문자나 블로거 사진은 저장하지 마.
3) 네이버 블로그에서 '<가게명 지역>' 후기 3~5개를 읽고 요약해 줘: 칭찬한 점, 아쉬운 점, 많이 시킨 메뉴, 분위기·주차, 제목 짓는 방식, 글 구성과 말투. 내용을 베끼지 말고 요약만 하고, 각 글의 제목과 주소를 적어 줘.
```
